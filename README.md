# HIWIN

Professional industrial company website starter project.

## Structure

- `index.html` - Home page
- `about.html` - About page
- `products.html` - Products page
- `product-details.html` - Product details page
- `contact.html` - Contact page
- `search.html` - Search page
- `assets/css/` - Stylesheets
- `assets/js/` - JavaScript files
- `assets/images/` - Image assets and placeholders
- `assets/fonts/` - Font assets

## Notes

- HTML5 boilerplate is included in every page.
- CSS and JavaScript files are linked correctly.
- No UI design or content is added yet.
- Ready for future PHP and MySQL integration.
